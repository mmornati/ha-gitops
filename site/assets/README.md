# Provenance

`panel-desktop-light.webp`, `panel-desktop-dark.webp`, `panel-phone-light.webp` and
`panel-phone-dark.webp` are real screenshots of the HA GitOps panel
(`gitops_backup/rootfs/app/panel/index.html`, version 0.5.0), taken on 2026-11-15 with
headless Chrome at 2x against a local demo controller. The repository, commits, files
and pull request shown are demo data. No image here is generated.
